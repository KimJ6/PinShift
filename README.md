# PinShift

**핀의 배치와 물리적 특성을 조정해 구슬의 낙하 경로를 설계하는 웹 기반 2D 물리 시뮬레이션 게임**

구슬의 움직임과 정산 결과를 관찰하고, 얻은 자원을 다시 투자하며 다음 라운드의 전략을 개선합니다.

**[🎮 웹에서 플레이](https://pin-shift-q40s52r89-kimj6s-projects.vercel.app/)**

## 게임 소개

PinShift의 핵심은 **확률에 맡기는 것에서 그치지 않고, 물리적 환경을 직접 설계하는 것**입니다. 플레이어는 핀의 위치와 설정값을 조절해 구슬의 움직임에 개입하고, 결과를 확인하며 배치를 개선할 수 있습니다.

게임은 **설계 → 관찰 → 개선**을 반복하는 라운드 구조로 진행됩니다. 구슬은 핀 구매·업그레이드에 쓰이는 재화이자 라운드에 투입하는 자원이며, 모두 소진하면 게임이 종료됩니다.

## 게임 플레이

1. **준비:** 보유 구슬로 핀을 구매하고, 설치 위치와 물리 설정을 조정하거나 개별 핀을 업그레이드합니다.
2. **투입:** 이번 라운드에 사용할 구슬 수를 선택하고 라운드를 시작합니다.
3. **시뮬레이션:** 구슬이 Box2D 물리 시뮬레이션에 따라 이동합니다. 발사대 각도를 조절해 발사 방향에 영향을 줄 수 있습니다.
4. **정산:** 각 구슬이 도착한 하단 결과 칸에 따라 보상 또는 손실을 적용합니다.
5. **반복:** 남은 구슬로 배치를 수정하고 다음 라운드를 진행합니다. 구슬이 소진되면 게임 오버입니다.

### 기본 조작

| 조작 | 기능 |
| --- | --- |
| 상점의 핀 선택 | 구슬을 사용해 핀 구매 |
| 구매 핀 드래그 | 준비 단계에서 설치 위치 변경(재배치 비용 없음) |
| 핀 선택 후 설정 패널 | 개별 핀 업그레이드 및 허용 범위 내 매개변수 조절 |
| 게임 필드 위 마우스 휠 | 발사대 각도 조절(준비·시뮬레이션 중 가능) |
| 투입량 조절 및 시작 버튼 | 라운드에 투입할 구슬 수 결정 및 실행 |
| 속도 버튼 | 시뮬레이션 속도 변경(1× / 2× / 4× / 8×) |

## 핵심 시스템

### 네 종류의 특수 핀

| 핀 | 물리적 특성 및 역할 |
| --- | --- |
| **탄성 핀** | 높은 반발을 이용해 구슬의 진행 방향 변경 |
| **흡수 핀** | 낮은 반발을 이용해 구슬의 움직임 완화 |
| **경사 핀** | 충돌면의 방향과 각도로 구슬 경로 유도 |
| **회전 핀** | 모터로 회전하며 충돌을 통해 구슬의 움직임 변화 |

기본 핀은 좌우로 움직이는 행을 이루며 플레이어가 직접 이동시킬 수 없습니다. 구매한 특수 핀은 준비 단계에서 배치 가능한 위치로 옮길 수 있습니다.

### 개별 배치와 업그레이드

- 구매한 핀은 라운드가 바뀌어도 유지되며, 준비 단계에서 무료로 재배치할 수 있습니다.
- 핀마다 **독립적인 레벨과 설정값**을 가집니다.
- 업그레이드는 물리값을 일괄적으로 강화하는 대신 **선택 가능한 설정 범위를 확장**합니다.
- 핀의 크기·위치 변경은 설치 가능 영역과 다른 핀과의 중첩 여부를 검증합니다.

### 구슬 경제와 위험 관리

- **구슬 하나가 재화·투입 자원·생존 자원**을 모두 담당합니다.
- 하단에는 안정적인 회수 칸과 높은 보상·손실을 기대할 수 있는 칸이 함께 배치됩니다.
- 라운드에 따라 보상과 손실 조건이 달라지므로, 핀에 투자할 구슬과 다음 라운드에 투입할 구슬 사이에서 선택해야 합니다.
- 모든 구슬은 결과 칸에 대해 한 번씩 정산됩니다.

구체적인 수치와 규칙은 [`public/config/`](public/config/)의 CSV 파일 및 [`web/src/scoring.ts`](web/src/scoring.ts)에서 확인할 수 있습니다.

## 기술 스택 및 아키텍처

| 기술 | 역할 |
| --- | --- |
| **Box2D 3 / box2d3-wasm** | 충돌·반발·마찰·센서·회전 관절·모터를 이용한 물리 계산 |
| **TypeScript** | 게임 상태, 라운드 규칙, 입력 및 UI 구현 |
| **Web Worker** | 물리 시뮬레이션과 게임 로직을 메인 렌더링 작업과 분리 |
| **PixiJS** | 게임 필드, 핀, 구슬 및 시뮬레이션 결과 렌더링 |
| **Vite** | 로컬 개발 서버 및 프로덕션 빌드 |
| **CSV** | 구슬·핀·업그레이드·결과 칸·게임 규칙 설정 관리 |

```text
브라우저 메인 스레드
  ├─ 사용자 입력 및 UI
  ├─ PixiJS 렌더링
  └─ CSV 설정 로딩·검증
             │
             │ 명령 / 상태 스냅샷
             ▼
Web Worker (TypeScript)
  ├─ 핀 관리·라운드·구슬 경제·정산
  └─ Box2D 3 WebAssembly 물리 월드
```

물리 연산은 **사전 컴파일된 `box2d3-wasm` 패키지**를 Web Worker에서 불러와 수행합니다. 게임 규칙과 상태 관리는 TypeScript로 구현했으며, 별도의 C/C++ 게임 코어를 직접 빌드하는 구조는 아닙니다.

## 로컬 실행 방법

Node.js와 pnpm이 필요합니다. 저장소를 내려받은 뒤 프로젝트 루트에서 실행합니다.

```bash
pnpm install
pnpm dev
```

Vite가 출력하는 로컬 주소로 접속합니다. 소스 코드를 변경한 뒤 빌드와 테스트를 실행하려면 다음 명령을 사용합니다.

```bash
pnpm run build
pnpm test
```

Windows에서는 의존성 설치 후 [`Run_PinShift.cmd`](Run_PinShift.cmd)를 실행해 로컬 서버와 브라우저를 열 수도 있습니다. WebAssembly 및 Web Worker를 사용하므로 `index.html`을 `file://`로 직접 열어서는 정상 실행되지 않습니다.

## 프로젝트 구조

```text
PinShift/
├─ index.html                       # 웹 진입점
├─ web/src/
│  ├─ main.ts                       # 입력·UI 및 Worker 연동
│  ├─ game-renderer.ts              # PixiJS 렌더링
│  ├─ worker/physics.worker.ts      # 물리 월드·게임 상태·정산
│  ├─ config.ts                     # CSV 로딩 및 검증
│  └─ scoring.ts                    # 결과 칸 보상·손실 규칙
├─ public/config/                   # 게임 밸런스 및 물리 설정 CSV
├─ tests/run.mjs                    # 규칙 테스트
├─ THIRD_PARTY_NOTICES.md           # 외부 라이브러리 고지
└─ package.json                     # 의존성 및 실행 스크립트
```

초기 설정값은 `public/config/*.csv`에서 관리하며, 변경 사항은 새 게임을 로드할 때 적용됩니다.

## 테스트 및 검증

`pnpm test`로 표시 형식, 결과 칸의 보상·손실 계산, 핀 배치 검증, 고정 시간 간격 처리 등 일부 게임 규칙을 확인할 수 있습니다. `pnpm run build`는 TypeScript 검사와 프로덕션 빌드를 수행합니다.

자동 테스트는 **전체 브라우저 플레이와 물리 동작을 포괄하지 않습니다.** 실제 게임의 핀 설치·변경, 볼 낙하, 라운드 정산 등은 배포된 웹 페이지에서도 확인해야 합니다.
